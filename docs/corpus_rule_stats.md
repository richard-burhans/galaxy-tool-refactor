# Corpus per-rule isolation statistics

Generated by `python -m scripts.corpus_check rules` on 2026-06-06. Each GTR rule is run **in isolation** (no other rules) across the combined corpus (github + toolshed, sha256-deduplicated) to surface per-rule misbehaviour. fmt rules are gated on validation under any vendored profile and checked for idempotence + no-crash only; codemods use their own eligibility and are checked for idempotence + post-codemod validity. Failures are retained as regression fixtures in the owning tier.

Regenerated by every full run of `corpus_check.py rules` unless `--no-stats` is given; partial sweeps (`--limit` or `--repo`) do not regenerate it.
