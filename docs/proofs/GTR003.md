# GTR003 — Blank line between `<tool>` sections (fmt)

**Contract:** behaviour-preserving.
## Claim
Inserting a blank line into the tails of `<tool>`'s children is a no-op.

## Proof
`<tool>` is `xs:all` (element-only content) in all 28 vendored XSDs; XML 1.0
makes inter-element whitespace in element content non-significant. The rule
emits `SetTail` only for `<tool>`'s non-last children, and `safe_set_tail`
writes only a None/whitespace tail.

## Scope boundary
Root-level only — never descends into content-bearing subtrees (contrast
[GTR001](GTR001.md)'s guard, which exists exactly because deeper levels can be
mixed content).
