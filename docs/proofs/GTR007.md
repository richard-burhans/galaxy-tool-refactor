# GTR007 — UpdateProfile (upgrade step)

**Contract:** structural-only.
## Claim (contract)
**Structural-only**: declares the newest profile at which the tool is
XSD-valid. Runtime behaviour changes from profile bumps are the `upgrade`
contract's *point* and are surfaced separately (`behavior_preserving` flag +
the §23 per-tool warnings; `docs/profile_upgrades.md`).

## Proof
Validity at the declared profile is checked by construction
(`newest_valid_profile`); idempotent. The validity-vs-behaviour boundary is the
audited soundness boundary (codemod §22, §25).
