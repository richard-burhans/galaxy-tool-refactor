# GTR106: DropSelectCheckboxesDisplay, drop `display="checkboxes"`

**Contract:** behaviour-preserving (presentation attribute only).

## The transform
Remove `display="checkboxes"` from a `<param>` under `<inputs>` whose `type` is
`select` / `data_column` / `drill_down` **and** whose `multiple` and `optional`
attributes already agree with it (`multiple="true"`, and `optional` true —
`optional` defaults to `multiple`, per Galaxy).

## Proof
- **`display` selects a widget, nothing else.** It is read when the form is
  rendered and never participates in building the value or the command line: a
  `multiple` select submits the same list whether that list was drawn as
  checkboxes or as a multi-select box. So the rendered command is identical by
  construction, which is the strongest form of the guarantee this repository
  asks of a fixer.
- **It is optional in every vendored XSD** that allows the attribute, so
  dropping it cannot invalidate a tool that validates today.
- **The consistent-only precondition avoids deciding a contradiction.** A
  `checkboxes` select *without* `multiple`/`optional` is an inconsistency
  planemo reports (GTR076 here). There, dropping `display` would quietly settle
  a question the author may have meant the other way — the missing
  `multiple="true"` may be the real omission. Those are skipped and keep
  reporting through GTR076, so this fixer never resolves an ambiguity.
- **`display="radio"` is untouched.** IUC does not object to it and it
  constrains what a user can express in a way `checkboxes` does not, so it is
  out of scope rather than "fixed" by the same rule.
- **Idempotent.** After the drop there is no `display` to match.

## Scope (sizing, not soundness)
Classified `bulk-only` in `gate_eligibility.py`, not gate-eligible: the
transform is sound, but "no `display="checkboxes"`" is an **IUC review**
convention rather than a published standard — planemo's own linters police only
the `display` ↔ `multiple`/`optional` consistency, and nothing in the standards
text forbids the attribute. Offer it in the bulk pass; do not hard-gate an
incoming PR on it until IUC writes it down.
